# YourFitness Landing Page

This is the landing page for **YourFitness**, a clean and responsive fitness website.

## Project Structure

- `index.html` — Main HTML file that structures the webpage.
- `style.css` — Main stylesheet for layout and design.
- `utils.css` — Additional CSS utilities and helper classes.
- `images/` — Folder containing JPG image files used in the project.

## Features

- Responsive design that works on desktop and mobile.
- Clean and modern fitness landing page layout.
- Optimized images for faster loading.
